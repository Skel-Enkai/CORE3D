Learning OpenGL with https://learnopengl.com/ and https://www.youtube.com/@VictorGordan. 
This repository is me learning OpenGL along with tutorials and playing around with what I've learnt, hoping to build a small 3D game engine!

After completing most of the tutorials to build an OpenGL engine, adding in improvements to code structure where I could, I decided to build a realistic mirror simulation in the engine without path-tracing or raytracing; relying solely on 4x4 affine transformation matrices, projection matrices and framebuffers.
